# First school runbook

1. Select an adult graduated-school cohort; exclude current/future graduation years and minors.
2. Create a campaign code without a person name, email, Instagram ID, or invite token.
3. Use a short-lived low-use invite. Do not expose member lists or personal drill-down.
4. Track masked aggregate stages only: approved, onboarding-ready, school-added, search, greeting, accepted, first reply, and report/block.
5. Counts below 10 remain `10명 미만`; never infer or publish the exact count.
6. Pause on privacy exposure, search bypass, message spam, report threshold, RLS/health failure, or operator anomaly.
