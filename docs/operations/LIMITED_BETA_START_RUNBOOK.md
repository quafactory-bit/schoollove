# Limited beta start runbook

1. Confirm migration history, RLS/FORCE RLS, grants, health, cron, and private SEO.
2. Complete `/admin/beta/setup`: name, period, maximum users, target scope, minimum features, invite limits, waitlist, stop conditions, and operator memo.
3. Save as `draft`, inspect warnings, then save as `validated`.
4. Activation creates a **paused** program only. It does not issue invites, enable public access, send OTP, or enable payment.
5. Issue a short-lived, low-use invite only after adult and consent checks are ready.
6. Approve one user at a time and verify ownership, graduated-school history, default privacy, and per-connection Instagram consent.
7. Start with account registration and private profile. Enable search, connections, messaging, and promotions separately.
8. Record decisions in tasks, notes, readiness, and audit without names, raw email, Instagram, search terms, messages, IP, cookies, or tokens.

Public launch is a separate decision and is never automatic.
