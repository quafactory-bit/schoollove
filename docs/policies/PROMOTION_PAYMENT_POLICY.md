# 프로모션 결제 정책 — 초안

상태: PHASE 10G LOCAL/DRAFT

- 광고 견적 수락으로 생성된 본인 주문만 결제할 수 있다.
- 주문번호, 금액, 통화는 서버가 결정하며 브라우저가 보낸 금액으로 변경할 수 없다.
- PortOne sandbox와 수동 결제는 별도 상태로 기록한다. 실제 결제수단 정보는 스쿨러브아이 DB에 저장하지 않는다.
- provider가 `PAID`를 반환하고 store ID·TEST channel·주문 ID·주문 금액·통화가 정확히 일치한 뒤에만 결제 완료와 광고 예약 가능 상태가 된다.
- 실패·취소·만료 callback만으로 결제 완료가 되지 않는다.
- 중복 요청과 webhook 재전송은 최초 결과를 재사용하며 이중 결제 완료를 만들지 않는다.
- 영수증은 provider의 불투명 reference만 보존한다. 현금영수증·세금계산서는 요청 상태만 준비하며 자동 발행하지 않는다.
- 환불은 provider 호출 전에 DB에서 잔여 한도를 멱등 예약하며, 성공한 provider reference를 받은 예약만 완료 처리한다. Production 자동 환불은 별도 승인 전 비활성이다.
