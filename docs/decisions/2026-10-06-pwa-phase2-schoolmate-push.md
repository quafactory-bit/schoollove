# 2026-10-06 — PWA Phase 2 동창 등록 웹 푸시

## 승인된 목표

- 사용자가 학교와 졸업연도를 등록하면 같은 학교·같은 졸업연도를 이미 등록한 다른 성인 계정의 알림 구독 기기에 동창 등록 알림을 보낸다.
- 알림에는 이름, 인스타그램주소, 반, 계정 식별자 등 개인을 식별하는 내용을 넣지 않는다.
- 알림 클릭은 `/school/{slug}/{year}?utm_source=push`로 이동한다.

## 사용자 동의와 UI

- 브라우저 알림 권한은 학교 등록 성공 뒤의 `알림 받기` 버튼이나 `/account`의 `동창 알림` 켜기 버튼을 직접 누른 경우에만 요청한다.
- 등록 성공 안내에서 `나중에`를 누르거나 권한을 거절하면 7일 동안 같은 안내를 다시 표시하지 않는다.
- iOS Safari는 홈 화면에 설치된 상태에서만 구독을 시도하며, 설치 전에는 홈 화면 설치 안내를 보여 준다.
- `/account`의 설정은 현재 기기의 구독을 켜거나 끈다. 다른 기기의 구독은 해당 기기에서 별도로 관리한다.

## 저장·권한 경계

- `public.push_subscriptions` 한 개 테이블을 PWA Phase 2 예외로 추가한다.
- 구독 행은 `auth.users.id`를 참조하고 Auth 사용자 삭제 시 cascade 삭제한다.
- `anon`과 `authenticated`에는 테이블 권한이나 정책을 주지 않는다. 로그인 검증을 마친 서버 API만 service role로 구독을 저장·삭제한다.
- 탈퇴 요청 RPC는 해당 계정의 구독을 같은 transaction에서 즉시 삭제한다.
- VAPID 개인키는 서버 환경변수에만 보관하고 저장소·클라이언트 번들·로그에 넣지 않는다.

## 발송 경계

- 학교 등록 응답 뒤 Next.js `after()`에서 발송하므로 푸시 실패가 학교 등록 성공을 되돌리거나 지연시키지 않는다.
- 이벤트당 최대 500개 구독을 조회하고 50개 단위로 `Promise.allSettled` 처리한다.
- 구독 endpoint의 SHA-256 해시를 사용한 Upstash `SET NX EX 86400`으로 구독 1건당 24시간 최대 1회만 발송한다.
- Upstash 또는 VAPID 설정이 없으면 발송하지 않는다.
- 푸시 서비스가 404 또는 410을 반환하면 만료된 구독을 삭제한다.
- 서비스 워커는 기존처럼 같은 origin의 navigate 요청과 오프라인 문서만 다룬다. 푸시 추가로 HTML·API·이미지 캐시 범위를 넓히지 않는다.

## 운영 적용 경계

- 코드, migration, 패키지, 테스트와 문서의 로컬 구현은 승인됐다.
- Supabase 원격 migration, Vercel 환경변수 등록, Production 배포와 실제 기기 발송은 로컬 검증 결과를 확인한 뒤 별도 적용 단계로 진행한다.
