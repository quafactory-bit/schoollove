# 인스타그램주소와 학교 레벨 안내

사용자는 제안 문구를 검토한 뒤 사이트 전체 수정과 배포를 승인했다.

- 서비스 목적은 기억하는 학교와 이름으로 친구를 찾고, 연결 후 상대가 허용한 인스타그램주소를 확인하는 것이다. 화면의 Instagram/인스타그램 표현을 문맥에 맞는 ‘인스타그램주소’로 정리한다. 인스타그램 비밀번호·전체 URL 입력을 새로 요구하지 않으며 기존 아이디 입력 형식은 안내한다.
- 학교 레벨은 함께 즐기는 부가 경험이다. 성장·성장판 대신 학교 레벨, 다음 레벨까지의 진행률, XP 적립을 설명한다. XP 적립을 실제 레벨 상승으로 단정하지 않고 주간 순위는 기존 최근 7일 XP 기준을 유지한다.
- 일반 화면·관리자 화면·법률 고지의 베타라는 표시를 초대 프로그램/참여/운영으로 교체한다. 내부 beta 식별자·API·권한·초대·운영 계약은 유지한다. 법률 고지의 명칭 정리는 정보 처리 범위나 동의 조건의 변경이 아니다.
- 연결 상세의 메시지 미제공 안내는 삭제한다. 이미 권한과 상대별 승인을 통과해 반환된 상대 아이디가 있을 때만 인스타그램주소와 DM 안내를 표시한다. 숨겨진 주소를 얻기 위한 조회·권한 우회·자동 공유는 추가하지 않는다. 기존 dormant 메시지 코드·기능 gate는 보존한다.
- 홈·로그인·온보딩·내 계정·환영 안내·학교·검색·공유·연결·검색 메타데이터·앱 설명을 일관되게 정리한다. 공유 payload에는 상대나 소유자 개인정보를 추가하지 않는다.
- 승인 범위는 문구 및 필요한 줄바꿈/표시 조정, 회귀 검증, 커밋·푸시·Preview 확인·PR 병합·운영 배포다. DB·환경변수·Auth·기능 활성화·실제 사람 검색·초대·계정 데이터 변경은 포함하지 않는다.

검증과 배포 결과는 IMPLEMENTATION_LOG 및 릴리스 PR에 기록한다.
