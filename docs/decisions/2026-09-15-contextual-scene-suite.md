# 화면별 이미지와 영상 교체

사용자는 모든 화면에 맞는 이미지·영상을 제작하고, 기존 공성전에서 자막과 로고를 제거해 학교 순위 영역에 넣은 전체 결과를 요청했다. 이번 범위는 로컬 구현과 미리보기이며 배포는 포함하지 않는다.

- 홈: 성인 친구의 재회 이미지와 6초 무음 영상. 인스타그램주소 확인이라는 목적은 실제 HTML 설명으로 유지한다.
- 학교 검색: 졸업앨범과 돋보기. 로그인: 성인 친구와 추억 앨범. 가입: 체크리스트. 내 학교: 작은 학교 배지. 공유: 초대장. 내 연결의 빈 상태: 연결된 카드.
- 환영 안내 네 단계에 각각 재회, 체크리스트, 학교 배지, 연결 카드를 사용한다.
- 학교 상세: 기존 레벨 경계 1/2/4/7/10에 맞춘 다섯 교정 이미지. 계산과 접근 권한은 변경하지 않는다.
- 학교 순위: 기존 공성전 원본 세 편을 사용한 자막·로고 없는 7.5초 무음 영상. 실제 순위는 기존 공개 집계로 표시한다. 전투 기능이나 가짜 순위를 만들지 않는다.
- 영상은 정지 이미지부터 표시하고 화면 안에서만 재생하며, 정지 버튼과 reduced-motion 대응을 제공한다. 개인 정보, API, DB, 공유 payload와 기능 허용 조건은 유지한다.

새 시각 자료는 public/images/scenes 및 public/videos/scenes에 보관한다. local fixture에서 전체 화면과 단계별 학교를 검토한다.
