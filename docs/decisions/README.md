# Architecture Decisions

이 폴더는 설계 과정에서 왜 이런 결정을 했는지를 기록합니다.

Design Package는 "무엇을 만들 것인가"를 정의합니다.

Decisions는 "왜 이렇게 만들기로 했는가"를 기록합니다.

---

## 파일명 규칙

YYYY-MM-DD-title.md

예시

2026-07-09-schoolhub-state.md

2026-07-10-level-policy.md

2026-07-12-search-policy.md

---

## 기록 대상

- 구조 변경 이유
- 정책 변경 이유
- Product Principle 변경 이유
- Design Package에 영향을 주는 결정

---

## 기록하지 않는 것

- 개발 진행 상황
- 버그 수정
- 기능 완료

이 내용은 IMPLEMENTATION_LOG.md 에 기록합니다.
