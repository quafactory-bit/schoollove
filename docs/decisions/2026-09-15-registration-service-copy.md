# 회원가입의 운영 서비스 안내

- 승인: 사용자가 회원가입 단계의 ‘베타’ 표현을 삭제하고 실제 운영 서비스로 안내하도록 요청했다.
- `/onboarding`과 가입을 진행하는 `/account`의 사용자 문구에서 ‘베타’를 제거한다. 초대 기능은 ‘사람 찾기 참여’, ‘초대 기능’으로 안내하되 초대·운영자 승인 조건은 유지한다.
- `/account`의 기존 `launch.registrationEnabled`가 참이고 긴급 중단이 아닐 때 운영 중인 서비스와 비공개 프로필·학교 등록을 안내한다. 닫힘·중단·상태 확인 실패를 운영 중으로 표시하지 않는다.
- 준비 중이라는 추측 대신 현재 이용·저장 가능 여부를 안내한다. `/login`에는 기존에 베타 문구가 없으므로 로그인 가용성 안내를 유지한다.
- 문구 변경만 승인됐다. 내부 beta 계약·식별자·권한·API·DB·기능 활성화 조건을 변경하지 않는다. Home·연결 화면·법률 문서의 다른 문구 변경과 원격 배포는 이 작업에 포함하지 않는다.

상태: LOCAL_VERIFIED. 검증 결과는 `docs/IMPLEMENTATION_LOG.md`에 기록했다. 원격 반영은 하지 않았다.

후속 승인: 사용자가 환영 팝업과 함께 이 문구 변경의 운영 배포를 승인했다. 애플리케이션 배포에 필요한 커밋·푸시·PR 병합이 포함되며, DB·환경변수·기능 활성화 설정은 변경하지 않는다.
