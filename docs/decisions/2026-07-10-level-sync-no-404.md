# Level Sync Route — 404 미구현 결정

Date: 2026-07-10

## Decision

POST /api/admin/tools/level-sync는 학교를 찾을 수 없는 경우를 나타내는 404 응답을 만들지 않는다. getSchoolLevelSnapshot 조회가 null이면 500 { error: 'Snapshot failed' }로, syncSchoolLevel 실행이 null이면 500 { error: 'Sync failed' }로 처리한다.

## Reason

getSchoolLevelSnapshot(그리고 syncSchoolLevel)의 현재 계약은 "row 없음"과 "조회/쓰기 오류"를 구분하지 않고 둘 다 null로 합쳐서 반환한다. 이 계약을 유지하는 한 Route Handler는 null의 원인이 "존재하지 않는 학교"인지 "일시적 DB 오류"인지 알 수 없다. 근거 없이 404로 단정하면 실제로는 일시적 오류인 상황을 "학교 없음"으로 잘못 표시하게 되므로, 원인을 구분할 수 없는 실패는 모두 서버 오류(500)로 처리한다.

## Impact

- app/api/admin/tools/level-sync/route.ts는 404를 반환하지 않는다.
- lib/api/levels.ts(getSchoolLevelSnapshot, syncSchoolLevel)의 null 계약을 이후 read error/not found를 구분하는 형태로 바꾸기 전까지는, 이 계약에 의존하는 다른 API도 동일한 원칙(원인 불명 실패는 500)을 따라야 한다.
- 향후 두 원인을 구분하고 싶다면 lib/api/levels.ts의 반환 계약 자체를 변경하는 별도 결정이 필요하다.

## Status

APPROVED
