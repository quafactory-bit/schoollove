# 내 계정 환영 안내 팝업

사용자가 환영 인사, 가입 단계, 학교 상태, 내 연결을 설명하는 팝업을 요청했다.

- `/account`에 4단계 안내와 항상 다시 열 수 있는 ‘이용 안내’ 버튼을 추가한다.
- 공개 가입 허용·긴급 중단 아님·탈퇴 중 아님·가입 미완료인 경우 브라우저 탭당 한 번 자동 표시한다. 완료 계정은 수동으로 연다. 자동 표시 여부는 버전별 sessionStorage 불리언 한 개만 사용하고 개인정보·계정 ID·행동 로그는 저장하지 않는다. 저장소 실패 시 자동 표시는 생략하고 수동 안내는 유지한다.
- 가입 단계는 Google 로그인, 만 19세 이상 자기진술, 필수 동의, 비공개 프로필, 학교 등록이다. 기존 owner state에서 완료 여부와 학교 수만 받아 표시하며 추가 조회하지 않는다.
- 학교의 비공개 이력과 성장 레벨·진행률의 의미를 설명한다. 공개 학교 성장과 내 계정 수치의 반영 시점 차이를 설명하고 가짜 레벨·인원·활동을 만들지 않는다.
- 내 연결은 수락된 상대별 카드와 이름·‘연결 확인’으로 설명한다. 사람 찾기 초대·운영자 승인 조건, 별도 메시지·Instagram 권한을 유지한다. 가입/학교 레벨만으로 권한이 생긴다고 안내하지 않는다. 베타라는 단계명은 사용하지 않는다.
- native dialog, 키보드 포커스 제한·복귀, Escape·닫기, 이전/다음, 작은 화면 내부 스크롤을 제공한다. 완료 버튼은 팝업만 닫으며 등록이나 권한 변경을 실행하지 않는다.
- 기존 미커밋 회원가입 문구 변경을 보존한다. 인증·권한·API·DB·패키지·원격 설정 변경 및 배포는 포함하지 않는다.

상태: LOCAL_VERIFIED. 구현/검증은 `docs/IMPLEMENTATION_LOG.md`에 기록했다. 원격 반영은 하지 않았다.

후속 승인: 사용자가 검토한 팝업과 가입 문구의 배포를 승인했다. 필요한 커밋·푸시·PR 병합과 운영 애플리케이션 배포를 진행한다. 이 승인은 DB·환경변수·기능 활성화 변경을 포함하지 않는다. 실제 배포 결과는 별도로 기록한다.
