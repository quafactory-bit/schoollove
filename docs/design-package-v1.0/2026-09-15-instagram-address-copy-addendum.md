# 인스타그램주소 중심 안내

[승인 결정](../decisions/2026-09-15-instagram-address-service-copy.md)에 따라 서비스 소개는 학교 친구와 연결 후 상대가 허용한 인스타그램주소 확인을 설명한다. 학교 레벨은 참여 재미로 소개하고 실제 XP/레벨 계산은 유지한다. 사용자와 관리자 화면에서 베타·성장판 명칭을 제거하며 초대·승인 조건은 보존한다. 연결 상세는 허용된 상대 주소가 있을 때만 DM 연락 안내를 표시한다. 법률 고지의 명칭만 정리하고 기존 정보 처리·동의·권한 경계는 변경하지 않는다.
