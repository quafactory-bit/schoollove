# SchoolLoveI Product Constitution v1.0

Status: **FROZEN**
Version: **v1.0**

## 0. 이 문서의 역할

이 문서는 SchoolLoveI 제품 판단의 최상위 기준이다.

화면, 기능, 데이터, API, SEO, 운영 판단이 충돌하면 이 문서와 `02-product-principles.md`의 원칙이 우선한다.

> 새로운 철학을 추가하지 않는다. 기존 원칙을 구현한다.

---

## 1. 제품 정의

**SchoolLoveI는 사람을 발견하는 서비스다. 학교를 검색하는 서비스가 아니다.**

학교는 사람을 발견하기 위한 시작점이다.

사용자는 학교 이름으로 들어오지만, 최종 목적은 같은 시절을 지나온 사람을 발견하는 것이다.

```text
학교
  ↓
기수
  ↓
반
  ↓
사람
  ↓
공개 인스타그램
```

School → Year → Class는 서로 다른 페이지의 나열이 아니라, **같은 사람 목록을 점점 좁히는 필터**다.

---

## 2. 제품의 핵심 약속

SchoolLoveI는 사용자에게 세 가지 감각을 제공한다.

1. **발견 우선** — 들어오면 먼저 사람을 발견한다.
2. **등록은 기여** — 입력 폼을 채우는 것이 아니라 우리 학교를 성장시킨다.
3. **성장은 체감** — 레벨 숫자 자체보다 학교가 살아 움직이고 있다는 감각을 준다.

---

## 3. 판단 우선순위

모든 제품 판단은 아래 순서를 따른다.

1. 학교보다 사람
2. 페이지보다 필터
3. 등록보다 발견
4. 입력보다 기여
5. 레벨보다 성장

원칙과 기능이 충돌하면 **원칙이 이긴다.**

---

## 4. 두 개의 핵심 루프

### 4.1 Discovery Loop

```text
Google / Naver / 내부 검색 / Home Feed
  ↓
School Hub
  ↓
Year Hub
  ↓
Class Hub
  ↓
Profile Card
  ↓
Instagram
```

사람을 발견하는 루프다.

School Hub 이후의 계층은 사람 목록을 좁히는 필터로 동작한다.

### 4.2 Growth Loop

```text
등록 CTA
  ↓
Register Flow
  ↓
등록 완료
  ↓
학교 상태 갱신
  ↓
Level 재계산
  ↓
Home Feed 성장 순간 생성
  ↓
다른 사용자의 발견
  ↓
다시 등록
```

등록은 Growth Loop의 엔진이다.

---

## 5. 프라이버시 경계

SchoolLoveI는 활동 로그와 사람 명단을 구분한다.

| 영역 | 사람 표기 | 원칙 |
|---|---|---|
| Home Feed | 익명 | 성장 활동을 보여준다 |
| Year / Class / Profile Card | 실명(`nickname`) + 공개 인스타 | 사람 발견이라는 서비스 본질 |

- Home Feed에 개인 이름이나 인스타그램 ID를 노출하지 않는다.
- 명단에는 서비스 목적상 이름과 공개 인스타그램을 표시할 수 있다.
- 공개 인스타그램 계정만 등록 가능하다.
- 잘못된 정보, 사칭, 무단 등록은 신고·수정·삭제 흐름으로 대응한다.

---

## 6. P1에서 하지 않는 것

- 로그인 / 회원가입을 제품 중심에 두지 않는다.
- 독립 개인 Profile 페이지를 만들지 않는다.
- 개인 프로필 꾸미기를 만들지 않는다.
- 댓글, 좋아요, 팔로우, DM, 반응 기능을 만들지 않는다.
- 연락처, 위치, 숨겨진 정보, 비공개 계정 정보를 찾지 않는다.
- 검색 결과를 SEO 랜딩으로 사용하지 않는다.
- Home Feed를 광고 피드나 SNS 피드로 만들지 않는다.
- 기존 제품을 새 프로젝트로 다시 만들지 않는다.

---

## 7. 리팩터링 원칙

v1.0은 신규 서비스 재작성 프로젝트가 아니다.

- 기존 코드 최대 재사용
- 기존 DB 최대 재사용
- 기존 API 최대 재사용
- 기존 URL 계층 유지
- P1만 구현
- P2 / Future는 구현하지 않음

설계가 불명확하면 임의 구현하지 않는다.

---

## 8. 최종 한 문장

> **SchoolLoveI는 학교를 통해 사람을 발견하고, 등록을 통해 학교의 성장을 체감하게 하는 서비스다.**
