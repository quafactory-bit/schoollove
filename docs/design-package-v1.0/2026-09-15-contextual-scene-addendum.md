# 화면별 시각 자료 — 승인된 보완

2026-09-15 사용자 요청에 따라 기존 공통 부유 학교 그림을 화면 목적에 맞는 새 이미지로 교체한다. 홈은 성인 친구의 재회, 검색은 앨범과 돋보기, 로그인은 추억 앨범, 가입은 체크리스트, 내 학교는 배지, 공유는 초대장, 내 연결은 연결된 카드로 표현한다. 환영 팝업 네 단계에도 같은 이미지 체계를 적용한다.

학교 상세는 다섯 개의 독립 교정 이미지를 기존 1/2/4/7/10 레벨 경계로 표시한다. 기존 SVG 문·교복 인물 중첩 대신 새로운 완성 이미지를 사용한다. 레벨 계산·비하락·State D·권한은 바꾸지 않는다.

홈 재회 영상은 6초, 학교 순위 공성전은 7.5초 무음으로 보여준다. 공성전은 사용자가 만든 원본 세 장면에서 자막과 로고가 추가되기 전 자료를 편집했다. 순위와 학교명은 실제 집계를 HTML로 표시하며 영상에 삽입하지 않는다. reduced-motion, 화면 밖·탭 비활성 정지, 수동 정지, 영상 오류 시 정지 이미지 대체를 제공한다.

연결 상세는 허용된 인스타그램주소와 기존 조작을 중심으로 유지한다. 개인정보와 기능 상태는 기존 계약을 따른다. 검토용 예시는 로컬 fixture에만 둔다.
