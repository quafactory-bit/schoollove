# Anonymous signup attribution addendum

The operator's 2026-10-14 instruction approves seven-day browser first-touch attribution and four validated UTM parameters for Web Analytics. This narrowly supersedes the no-query/no-client-persistence analytics contract for these fields only. Existing auth/growth exclusions, account consent/ownership and share payloads are unchanged.

First private-profile completion creates one anonymous row containing KST date, source/medium/campaign/content and a safe landing path. No account identity, email, school, IP, User-Agent, timestamp or full referrer is stored. Existing account milestones prevent double counting without adding an attribution identity map. Remote release needs separate operator approval; privacy-policy text changes are proposed only.
