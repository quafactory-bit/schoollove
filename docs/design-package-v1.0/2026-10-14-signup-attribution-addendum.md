# Anonymous signup attribution addendum

The operator's 2026-10-14 instruction approves seven-day browser first-touch attribution and four validated UTM parameters for Web Analytics. This narrowly supersedes the no-query/no-client-persistence analytics contract for these fields only. Existing auth/growth exclusions, account consent/ownership and share payloads are unchanged.

First private-profile completion creates one anonymous row containing KST date, source/medium/campaign/content and a safe landing path. No account identity, email, school, IP, User-Agent, timestamp or full referrer is stored. Existing account milestones prevent double counting without adding an attribution identity map. The operator subsequently approved explanatory policy text, Git publication and Preview migration/deployment. The policy describes seven-day validity and refresh on next visit rather than promising automatic localStorage expiry. Production release and merge require separate approval.
