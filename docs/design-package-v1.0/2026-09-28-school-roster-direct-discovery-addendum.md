# 학교 명단과 바로 사람 찾기 — 승인된 보완

2026-09-28 사용자 결정과 [상세 결정 기록](../decisions/2026-09-28-school-roster-and-direct-discovery.md)에 따라, 가입을 마친 만 19세 이상 회원은 초대·참여 신청·운영자 승인 없이 본인이 등록한 학교에서 정확한 이름 기반 사람 찾기와 연결 요청을 이용할 수 있다.

학교 등록 화면에는 `학교에서 나를 표시하기` 항목을 별도로 둔다. 이 항목은 기본으로 선택되어 있으나 사용자가 제출 전에 해제할 수 있고, 해제해도 학교 이력 등록은 완료된다. 선택한 회원의 입력 이름 전체, 졸업연도, 저장한 학년별 반은 같은 학교를 등록하고 본인도 명단 표시에 참여한 성인 회원에게만 표시한다. 공개 인터넷, 검색엔진, 비참여 회원에게는 명단을 제공하지 않는다.

회원은 내 계정의 학교 카드에서 즉시 숨김으로 바꿀 수 있다. 숨김 상태에서는 본인의 명단 노출, 학교 명단 열람, 정확한 사람 찾기를 함께 중단한다. 기존 회원은 새 선택을 하지 않은 상태로 간주해 기본 비노출한다.

명단은 사용자·프로필·학교 이력 ID, 인스타그램주소, 사진, 소개, 이메일, 연결 상태, 활동 정보를 반환하지 않는다. 표시 이름은 신분증으로 확인한 실명이 아니라 사용자가 직접 입력한 이름이다. 긴급 중단, 성인·본인 소유 계정, 정확 일치, 일일 검색 제한, 불투명 토큰, 차단·신고, 연결 후 Instagram 별도 허용 경계는 유지한다.
