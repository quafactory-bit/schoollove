# 개인정보 고지 보완 계약

권위: `docs/decisions/2026-09-15-privacy-notice-remediation.md` 및 사용자 승인.

- 개인정보 수집·이용 체크박스보다 앞에 항목·목적·보유기간·거부권·불이익을 표시한다.
- 같은 내용을 `/privacy#collection`과 `/account`에서 공통 컴포넌트로 제공한다.
- 선택 정보는 필수 정보와 구분하고 미입력으로 기본 계정 이용을 제한하지 않는다.
- `/login` 및 복구 이메일 입력 화면에서 해당 인증 처리와 국외 처리 안내에 접근할 수 있다.
- 개인정보 보호책임자와 실제 연락처를 표시한다. 2026-09-15 사용자가 성명·이메일·전화 공개 정보를 제공했다.
- 처리위탁 고지는 공급자·업무·항목·국가·시기·방법·보유기간·거부 방법·효과를 구분한다.
- 확인된 고지와 구현된 삭제 절차는 별도 시행할 수 있다. 외부 사업자의 미확정 범위는 명시하며,
  일부 보완 배포를 국외 이전 전체 정비 완료로 표시하지 않는다.
- 기존 공개 범위, 계정·사람 찾기 권한, 선택 입력, 필수 동의 네 항목을 확대하지 않는다.
- 과거 동의 기록을 새 고지에 대한 동의로 덮어쓰지 않는다. 법적 재동의 필요성은 별도 확인한다.

## 2026-09-16 승인된 삭제 기준

[삭제 기준과 배포 결정](../decisions/2026-09-16-privacy-retention-release.md)에 따라 일반 탈퇴 후
실제 Auth 삭제와 인증 재사용 방지 대기 창을 확인한 뒤 식별 기록을 정리한다.
OTP 만료 정리와 24시간 발송 제한 예산을 분리하고 개인과 연결할 수 없는 일별 완료 건수만
최대 90일 보관한다. 안전 제재·실패한 삭제는 일반 정리 대상에서 제외한다.
