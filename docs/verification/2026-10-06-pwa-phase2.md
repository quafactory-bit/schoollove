# PWA Phase 2 동창 등록 웹 푸시 검증

상태: `PREVIEW_VERIFIED` (DB·배포) / `BLOCKED` (VAPID 환경변수)

## 구현 결과

- 학교 이력 등록 성공 뒤 `after()`에서 같은 학교·졸업연도의 다른 구독자에게만 알림 발송을 예약한다.
- 알림 payload는 학교명·졸업연도와 `/school/{slug}/{year}?utm_source=push`만 포함한다. 이름, 인스타그램주소, 반, 사용자 식별자는 포함하지 않는다.
- 구독별 24시간 제한은 endpoint의 SHA-256 해시를 사용한 Upstash `SET NX EX 86400`으로 처리한다.
- 이벤트당 최대 500개 구독을 50개씩 `Promise.allSettled`로 발송하며, 404/410 구독은 삭제한다.
- 로그인 사용자 구독/해지 API, 기존 관리자 쿠키 인증을 사용하는 현재 기기 테스트 API, 계정 토글, 등록 직후 소프트 안내, iOS 설치 안내를 추가했다.
- `push_subscriptions`는 Auth 사용자 cascade, RLS, client role 무권한, service role 명시 권한을 사용한다. 탈퇴 요청 RPC에서도 즉시 삭제한다.
- 서비스 워커 캐시는 계속 오프라인 문서 한 개와 같은 origin navigate 실패만 처리한다.
- 실제 VAPID 키 쌍은 Git 추적 밖의 로컬 보안 파일에 생성했다. Vercel 입력 검증 중 값이 로그인된 관리 화면과 내부 자동화 출력에 표시된 키 쌍은 폐기 대상으로 분류했고 실제 환경변수로 저장하지 않았다.

## 실행하지 않은 검증

- Vercel VAPID 환경변수 등록과 환경변수 반영 재배포는 완료하지 않았다. Production migration·환경변수·배포는 실행하지 않았다.
- 실제 Android Chrome, 설치된 PWA, iOS 홈 화면 앱의 구독·수신·클릭은 VAPID 미등록 상태이므로 실행하지 않았다.
- 실제 Upstash 24시간 제한과 실제 push provider의 404/410 응답은 원격 서비스를 호출하지 않고 통합 테스트 mock으로 검증했다.
- 실제 계정의 학교 등록, 구독 저장, 푸시 전송 등 원격 데이터 write를 하지 않았다.
