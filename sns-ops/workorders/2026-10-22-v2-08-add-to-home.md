# 작업지시서 v2-08 — 홈 화면에 추가 (PWA 설치 안내)

마스터 규칙 적용 · 예상 2시간 · 모델: Sonnet/Opus · 선행: 05·06 · 기준 화면: 목업 0·3번 · 재료: `pwa-wip-2026-10-06` 브랜치

## 1. 왜
- SNS 폴더에 들어가려면 홈 화면 아이콘이 있어야 하고, 푸시(09번)는 설치된 PWA에서만 온다(아이폰 포함).
- 설치 요청은 **가입 완료 직후 한 번**, 이득(알림 2종)을 붙여서.

## 2. 작업
1. `pwa-wip-2026-10-06` 브랜치의 `app/manifest.ts`, `components/pwa/*`, `app/manifest.test.ts`, `next.config.ts` 변경을 `v2-simplified`로 가져온다(cherry-pick 또는 수동 병합). 아이콘 PNG는 **새 이름** `public/icons/icon-v2-192.png`, `icon-v2-512.png`, `icon-v2-maskable-512.png`로 새로 만든다(목업 0번: 초록 `#0f7b5f` 둥근 사각형 + 흰 체크. SVG 원본 `public/icons/icon-v2.svg`도 저장). 기존 `icon-192/512.png`는 덮어쓰지 않는다.
2. `app/manifest.ts`: `name` "스쿨러브아이"(10번에서 치환), `short_name` **3글자**(지금은 "출석부"로 두고 10번에서 확정), `display: standalone`, `start_url: /account`, `theme_color: #0f7b5f`, `background_color: #ffffff`, 아이콘은 v2 파일.
3. 설치 안내 화면 `app/onboarding/installed/page.tsx`(목업 3번): 아이콘 · 제목 `홈 화면에 추가하면 같은 기수가 들어올 때 알려드려요` · 이득 3줄(새 동문 알림 / 요청·수락 알림 / 그 외 알림·광고 없음) · 안드로이드: `beforeinstallprompt` 이벤트를 잡아 둔 뒤 버튼 `홈 화면에 추가`로 네이티브 설치 시트 호출 · 아이폰(Safari 감지): 회색 안내 `사파리 아래 공유 버튼 → 홈 화면에 추가` + 그림 · 이미 설치된 상태(`display-mode: standalone`)면 이 화면을 건너뜀 · `나중에` 링크 → `/account`. **이 화면은 가입 완료 직후 1회만**, 이후 재표시는 `/account` 더보기 메뉴의 `홈 화면에 추가`로만.
4. 서비스워커: 오프라인 캐시는 최소(앱 셸만). 푸시 수신 핸들러의 자리만 만들어 두고 실제 구독은 09번.
5. 검증: Lighthouse PWA 설치 가능 조건 통과(manifest·SW·HTTPS). 모바일 Chrome 에뮬레이션에서 `beforeinstallprompt` 발생 확인(Playwright로 가능한 범위), 아이폰 안내 분기 렌더 테스트.
6. 커밋 `v2-08: installable PWA with post-signup add-to-home screen`.

## 3. 운영자 확인(2차 후)
- 안드로이드 폰: 가입 → 설치 시트 → 홈 화면 아이콘 → 열면 `/account`.
- 아이폰: 가입 → 안내 → 공유 → 홈 화면에 추가 → 아이콘 라벨 3글자 확인.

## 4. 하지 않는 것
- 스토어 등록(별도). 기존 아이콘 파일 덮어쓰기 금지. 설치 안내를 홈·학교 페이지 등 다른 곳에 띄우지 않음.
