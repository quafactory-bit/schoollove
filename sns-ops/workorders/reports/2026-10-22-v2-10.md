## 운영자 체크리스트 (도메인 구매·연결 뒤, 이 순서)
1. 도메인 `chulseokbu.kr` 구매 → Vercel → `schoollove-kr` → Settings → Domains → `chulseokbu.kr`과 `www.chulseokbu.kr` 추가, 안내되는 DNS 레코드 등록.
2. Google Cloud Console → API 및 서비스 → 사용자 인증 정보 → 출석부 로그인에 쓰는 OAuth 클라이언트 → 승인된 리디렉션 URI에 `https://chulseokbu.kr/auth/social/callback/google` **추가**(옛 주소는 남김).
3. Supabase(운영 프로젝트) → Authentication → URL Configuration → Site URL은 그대로 두고 Redirect URLs에 `https://chulseokbu.kr/**` **추가**. 로그인 브로커의 발급자 주소가 도메인에 묶여 있어 브로커 설정도 새 도메인 기준으로 점검해야 한다 — 연결 뒤 함께 확인.
4. Threads 앱(Meta 개발자) 콜백 URL에 새 도메인 추가(옛 것 유지).
5. Vercel Production 환경변수: `NEXT_PUBLIC_SITE_URL` → `https://chulseokbu.kr`, `NEXT_PUBLIC_SITE_DOMAIN` → `chulseokbu.kr`(이 값을 넣는 순간 옛 도메인 리다이렉트가 켜짐), `SCHOOLLOVE_RECOVERY_EMAIL_FROM` 표시 이름을 `출석부`로.
6. Threads·인스타 아이디 `@chulseokbu`로 변경, 프로필 소개·링크 교체.
7. 구글 서치콘솔에 새 도메인 추가 + 주소 변경 도구.
