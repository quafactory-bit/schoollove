## 2. 지명 소환장 (새 표 ②)
`public.summons`

| 열 | 형식 | 규칙 |
|---|---|---|
| id | uuid PK | |
| share_code | text UNIQUE | 무작위 10자. 주소에는 이것만(`/summons/<code>`) |
| creator_user_id | uuid | auth.users 삭제 시 함께 삭제. **카드·페이지에 절대 표시 안 함** |
| school_id, graduation_year | uuid, int | 만든 사람이 같은 학교·졸업연도에 등록돼 있어야 생성 |
| target_name | text | 2~10자 한글/영문, 욕설·연락처·학생 표현(학생·중딩·고딩·○학년 등) 거부 |
| created_at | timestamptz | 1인 하루 3장(KST) |
| hidden_at, hidden_reason | timestamptz, text NULL | 'self_request'(내려 주세요) · 'report' · 'admin' · 'creator' |
| report_count | int | 신고 횟수(신고자 정보는 저장 안 함) |

- RLS + FORCE RLS, 직접 접근 없음. RPC: 만들기(로그인+같은 학교·연도+3장/일), 공개 조회(학교·연도·이름만, 숨김이면 없음), **"내 이름이 올라갔어요 · 내려 주세요" → 즉시 숨김**, 신고(누적 3회면 자동 숨김 — 기준은 운영자 결정), 관리자 목록·내리기.
- 페이지 `/summons/[code]`: noindex, 내려 주세요 링크 필수, 신고 버튼. 그 사람이 출석부에 있는지 표시하지 않음.
- OG 카드: `/summons/[code]/opengraph-image` 칠판 디자인 "[출석부 알림] OO고 2008년 졸업생 누군가가 '김민수'님을 찾고 있습니다".
- 집계: P0-1의 `summons_share_clicked` 이벤트 연결.
- **추가 확인 필요:** 이름 전체가 공개 URL로 퍼지므로 개인정보처리방침에 소환장 항목(목적·보관 기간·삭제 요청)을 넣어야 한다. 보관 기간 제안: 생성 90일 후 자동 숨김.

## 3. 잠금 게이지 (새 표 없음, 규칙 변경)
지시서 문구: "같은 학교·졸업연도 동창 2명만 더 출석하면 [우리 학년 비밀 칠판 & 전체 목록]이 열립니다! (현재 1/3명)"

| 같은 학교·졸업연도 출석 수 | 지금(v2) | 제안 |
|---|---|---|
| 1~2명 | 같은 학교 명단 전체 보임 | 학교 명단은 그대로 보임. **우리 학년 칠판(근황 태그·한마디 모아보기)만 잠금** + 게이지 "현재 n/3명" |
| 3명 이상 | 같음 | 우리 학년 칠판 열림 |

- 기존에 보이던 명단을 새로 잠그면 이미 가입한 사람이 갑자기 못 보게 되므로, 제안은 "새로 생기는 칠판만 잠금"이다. 지시서의 "전체 목록"까지 잠글지는 운영자 결정.
- 1클릭 노크: 출석부 명단의 기존 연결 요청 버튼(`components/roster/RosterRowButton.tsx`, 상호 수락 규칙 동일)을 가입 직후 화면에도 보여 주는 방식으로 새 표 없이 가능.
