## 한 일
1. **PWA 재료:** `pwa-wip-2026-10-06`의 `app/manifest.ts`·`components/pwa/*`·`app/manifest.test.ts`·`public/sw.js`·`public/offline.html`은 이미 main(#128)에 들어와 `v2-simplified`와 같다(차이는 v2 리다이렉트를 넣은 `next.config.ts`뿐). 따로 cherry-pick할 것이 없었다.
2. **아이콘(새 이름, 기존 파일 덮어쓰기 없음):** `public/icons/icon-v2.svg`(원본), `icon-v2-192.png`, `icon-v2-512.png`, `icon-v2-maskable-512.png`(모서리 없이 꽉 채우고 체크는 안전 영역 안), `apple-touch-icon-v2.png`(180, iOS용). 생성 스크립트 `scripts/v2/make-icons.mjs`(이미 있는 `sharp` 사용, 패키지 설치 없음).
3. **manifest:** `name` 스쿨러브아이, `short_name` **출석부**(3글자, 10번에서 확정), `start_url /account`, `display standalone`, `theme_color #0f7b5f`, `background_color #ffffff`, 아이콘 v2. 레이아웃의 favicon·apple-touch-icon도 v2 파일로.
4. **설치 안내 화면** `app/onboarding/installed/`(목업 3번): 아이콘 · `홈 화면에 추가하면 같은 기수가 들어올 때 알려드려요` · 이득 3줄 · 안드로이드: 미리 잡아 둔 `beforeinstallprompt`로 `홈 화면에 추가` 버튼이 네이티브 설치 시트를 띄움(이벤트가 없으면 브라우저 메뉴 안내) · 아이폰: 회색 안내 `사파리 아래 공유 버튼 → 홈 화면에 추가` · 이미 설치(standalone)면 건너뜀 · `나중에` → `/account`.
   - 가입 한 화면 완료 → 이 화면 → 출석부. **가입 직후 1회만**(이 기기 로컬 기록), 다시 보기는 계정 설정의 `홈 화면에 추가` 링크(`?again=1`)로만.
   - `beforeinstallprompt`는 페이지가 그려지기 전에 올 수 있어서 레이아웃 `<head>`의 작은 인라인 스크립트가 미리 잡아 둔다(브라우저 자체 설치 띠도 막힘).
5. **다른 곳의 설치 안내 제거:** 기존 `InstallPrompt`(두 번째 방문부터 모든 페이지 하단에 뜨던 띠)를 레이아웃에서 뺐다(파일은 그대로). 지시서 "홈·학교 페이지 등 다른 곳에 띄우지 않음".
6. **서비스워커:** 오프라인 셸(오프라인 문서 1개만 캐시)은 그대로. 푸시 핸들러는 09번 자리 표시 주석만.
