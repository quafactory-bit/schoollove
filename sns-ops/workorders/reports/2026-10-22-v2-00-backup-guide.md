# Supabase 백업 받는 법 (운영자용, 2026-10-22)

v2 1차 작업 전에 **운영자가 직접** 한 번 받아 둔다. 에이전트는 원격 DB에 접속하지 않는다.
v2는 DB에 "추가만" 하므로 되돌릴 때 DB를 손댈 일은 없지만, 만약을 위한 보관용이다.

## 1. 먼저 대시보드에서 확인 (모든 요금제)
1. https://supabase.com/dashboard 로그인 → SchoolLove 프로젝트 선택
2. 왼쪽 메뉴 **Database → Backups**
3. 보이는 내용에 따라:
   - **Pro 이상 요금제**: 날짜별 자동 백업 목록이 보인다. 오늘(또는 어제) 날짜 백업이 있는지만 확인하고 화면을 캡처해 둔다. 이걸로 끝.
   - **Free 요금제**: 자동 백업이 없거나 내려받기가 안 된다고 나온다. 아래 2번으로 직접 받는다.

## 2. 직접 받기 (Free 요금제, 또는 파일로 하나 더 갖고 싶을 때)
준비: Supabase CLI 설치·로그인, 저장소 폴더가 프로젝트와 연결(`supabase link`)되어 있어야 한다.

저장소 루트에서 운영자가 실행:

```bash
supabase db dump --linked -f backup-2026-10-22.sql
```

데이터 행까지 따로 받고 싶으면:

```bash
supabase db dump --linked --data-only -f backup-2026-10-22-data.sql
```

- 실행 중 DB 비밀번호를 물으면 대시보드 **Project Settings → Database**에서 확인해 입력한다(비밀번호를 채팅·문서에 붙여넣지 않는다).
- 만들어진 `.sql` 파일은 **저장소 밖**(예: 개인 클라우드 드라이브)으로 옮겨 보관한다. 개인정보가 들어 있으므로 git에 올리지 않는다.

## 3. 끝나면
- Claude Code에 "백업 받았어(대시보드/파일)"라고만 알려 주면 된다. 파일 내용·비밀번호는 알려 주지 않는다.
