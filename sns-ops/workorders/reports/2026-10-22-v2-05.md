1. **복구 이메일 단계: 이번엔 그대로.** 지시서는 "로그인 뒤 조건부 화면"으로 봤지만 실제로는 인증 브로커 안에서 새 계정 생성 전에 필수로 거치는 단계다(중복 계정 방지). 지시서의 "Google 로그인·세션 처리 변경 금지"와 충돌해 건드리지 않았다. 제거하려면 별도 설계·지시서가 필요하다.

## Preview 확인 절차 (운영자 필수 확인)
지금 Preview에서 실제 가입을 하려면 막힌 곳이 3개다.
1. **Vercel 로그인 보호:** Preview 주소는 Vercel 팀 로그인이 필요하다(이미 확인). 폰에서 보려면 Vercel → 프로젝트 → Settings → Deployment Protection에서 그 배포의 "Shareable Link"를 만들거나 폰 브라우저에서 Vercel에 로그인한다.
2. **Preview DB 일시정지:** `schoollove-preview`는 무료 요금제라 며칠 안 쓰면 다시 멈춘다. 테스트 직전에 Supabase 대시보드에서 상태를 확인하고 멈춰 있으면 Resume.
3. **Preview Google 로그인 꺼짐:** Preview 화면이 "로그인 준비 중"이다. 로그인 설정 스위치 `SCHOOLLOVE_SOCIAL_BROKER_EXPOSURE`(Vercel Preview 환경변수, 이름만 기재)가 `preview`가 아닌 것으로 보인다. 켜려면 Vercel Preview 환경변수 변경이 필요하다 — **환경변수 변경은 운영자 승인 사항**이라 하지 않았다. 브랜치 Preview 주소가 Google·브로커 콜백 허용 주소에 들어 있는지도 함께 확인해야 한다(8/23 Preview Google 활성화 기록 참고: `docs/decisions/2026-08-23-preview-google-activation-verification.md`).
- 위 3개가 풀리면: Preview에서 Google 가입 1회 → (새 계정이면 복구 이메일 확인) → 한 화면 입력 → `등록하고 출석부 보기` → `/account` 도달 → 학교 페이지 "현재 가입한 사람"에 본인 표시 확인. 06번 이후에는 출석부 화면에서 본인 표시 확인.
